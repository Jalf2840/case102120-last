## 今回の変更

「↺ 最初から読み返す」を押すと、最終章を**回答が一つも選ばれていない状態**から始められます。

- 5つの質問の以前の回答を消去します。
- 到達した場面、証言提出状態、CASE CLOSEDの日時を最終章だけ初期化します。
- 「最後の証言」の冒頭へ戻り、もう一度回答しながら最後まで進めます。
- 通常の「前の場面」「次の場面」「閲覧済み記録」操作は、以前と同じく回答を保持します。
- 本編 `case102120` の保存記録には一切影響しません。
- 画面下の CASE CLOSED にある「最初から読み返す」も同じ動作です。

※再プレイ後に最終章を解決すると、新しい解決日時が記録されます。
